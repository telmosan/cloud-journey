# Cloud Journey & Infrastructure Lab

Technical documentation, hands-on cloud labs, and infrastructure experiments tracking my progress across modern cloud platforms (Microsoft Azure and distributed systems architecture).

---

## 🎯 Objectives
* Build hands-on proficiency in core cloud computing services (IaaS, PaaS, SaaS) and infrastructure architecture.
* Prepare for and achieve industry-standard Microsoft Azure technical certifications.
* Implement cloud automation, virtual networking, security controls, and Infrastructure as Code (IaC).

---

## 🛠️ Stack & Environment

* **Cloud Platform:** Microsoft Azure (Azure for Students Subscription)
* **OS & Tooling:** Linux (Ubuntu/Xubuntu), Bash, Git, OpenSSL, cURL
* **Methodology:** Version-controlled workflows, modular technical documentation, and project-based labs.

---
